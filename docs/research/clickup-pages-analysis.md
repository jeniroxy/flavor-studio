## 0. Global facts that apply to every page in this scope

**Tech/animation stack (from JS chunk scan of 77 Next.js chunks + runtime probes)**

- Next.js (pages router) + Contentful images (`images.ctfassets.net`), CSS Modules (class names like `SectionWithNav_navWrap__60m9e`, `CuContentCardV5_wrapper`). No Tailwind, no Webflow.
- Animation: **GSAP + ScrollTrigger** (95/28 mentions), **Lenis** smooth scroll (31 mentions; `window.Lenis` present on `/brain/agents`), **Rive** (94 mentions; canvas on `/pricing` and `/brain`), `IntersectionObserver` reveal (41), CSS keyframe **marquees** (`marquee-left/right 120s`, `_scroll 60s`, `_slide-translate 60s`), a `typewriter` helper (2 mentions), `_shimmerStream 3s` (shimmer on hero CTA), `_logoEnter/_logoExit 0.2s` (logo strip swap). No Lottie, no Framer Motion, no Swiper (one stray mention).
- Standard feature/solution pages are **mostly static** (opacity-0 reveal elements = 0 on `/features/tasks`); heavy motion lives on `/brain` (21 opacity-0 reveal targets, 65 will-change, sticky pinned visuals) and `/brain/agents` (23 reveal targets, pinned hero with "KEEP SCROLLING" indicator, cube-spin & code-scroll keyframes).
- Transitions: `background-color .2s ease` (buttons/links), `opacity .25s cubic-bezier(.5,0,.5,1)`, `transform .2s ease`, `grid-template-rows .2s ease-out` (FAQ accordions animate via CSS grid rows 0fr→1fr), `all .25s ease-out`.

**Typography / tokens (computed)**

- Headline font: **Plus Jakarta Sans** (700 / 650 weights). Body: **Inter**. Eyebrows & data labels: **Sometype Mono** (uppercase, letter-spaced, `rgb(102,71,240)`-ish indigo on light, green `#14E08A` on dark).
- H1: 60px/66px 700, `rgb(32,32,32)`. Section H2: 48px 700. Sub-section H2/H3: 40px 650. Card title ~18px 650. Body 16–18px Inter, `rgb(100,100,100)` gray.
- **Signature headline treatment:** last 1–3 words fade to gray via `background: linear-gradient(98deg, #202020 43%, #8f8f8f 92%)` + `background-clip: text` ("Never lose **track of work again**", "All the features, one **platform**", "The best work **solution**, for the best **price**.").
- Buttons: primary `#202020` bg, white text, radius 12px, padding 12px 20px, 18px/650 with arrow "→"; secondary light gray `#f2f2f2` pill, radius 8–12px; nav buttons 14px/600 radius 8px. On dark pages the primary inverts to white-on-black; Brain² uses one orange accent CTA `rgb(236,54,9)` ("Try Brain² FREE").
- Containers: 1080px content column, 1120–1280px wide sections; cards radius 8px (grid cards), 12–15px (feature panels), 24–32px (hero blobs/agents). Card bg `#F7F7F9`/`rgb(248,248,252)`; shadows extremely light (`rgba(16,30,54,.06) 0 20px 60px`).
- Recurring UI atoms: star rating row "★★★★½ 25,000+ reviews from [G2/Capterra/GetApp/…]"; logo strip "TRUSTED BY THE BEST — amazon · NVIDIA · wayfair · verizon · Spotify · Stanford"; compliance strip "SOC 2 TYPE II · ISO 27001 · GDPR · HIPAA · 24/7 SUPPORT"; sub-CTA microcopy "No credit card. Setup in 2 min." / "Free forever. No credit card."
- Every page ends with the same footer (Download / AI / Product / Compare / Company / Help + certs + legal). Sticky top nav (`position: sticky; top:0`) with Login + Sign Up; a thin announcement bar ("NEW: Brain² — The best AI is _your_ AI…") sits above it on some pages.

## 7. VISUAL / MOTION NOTES SPECIFIC TO THESE PAGES

- **Backgrounds:** white page ground; alternating `#F7F7F9` cards rather than gray bands; **hairline-grid sections** (1px `#EAEAEA` cell borders, no fill) are the signature for alternating rows, stat grids and pillars. Dark sections are pure `#000` with a `1px rgba(255,255,255,.08)` grid and dot-matrix textures (`radial-gradient(48px, transparent calc(100% - 1px), rgba(20,224,138,.05)…)`).
- **Gradients:** (a) headline gray-fade text gradient; (b) CTA banners `black → #7c2bd6 → #ff2fd0 → #ffb38a` diagonal with `glow-vector.png`/`warm-vector.png` overlays; (c) final-CTA rainbow `blue #0091FF → magenta #FF02F0 → orange #F76808`; (d) card frames for screenshots: orange→pink, purple→violet, cyan→blue; (e) AI cards use `conic-gradient(#0091FF, #FF02F0, #F76808, #6647F0, #0091FF)` 1px borders (`GradientPill_rotatingGradientBorder 1.5s` spins it); (f) Brain² green `#14E08A` radial/conic glows.
- **Sticky:** top nav; sticky right rails (`top:120px`) on features index, automations, enterprise, case studies; Brain² pinned visual (`top:215px`) and pinned quote; `/brain/agents` fixed sub-nav (`top:60px`) and GSAP-pinned hero.
- **Scroll-pinned tab sections:** Brain² "sticky visual with 3 scrolling text blocks"; Agents pinned hero; everywhere else uses scroll-spy rails rather than pinning.
- **Marquees:** integration logos (2 rows opposite directions, 60s), skill chips (5 rows, 120s), Brain² event chips; all pure CSS `translateX` keyframes, pause not implemented.
- **Hover:** cards don't lift (transform stays `none`); links/buttons `background-color .2s`; agent carousel cards reveal a "+" button; buttons darken slightly. Lift/shadow hovers are absent — restraint is part of the look.
- **Reveal:** IntersectionObserver-driven opacity/transform (`opacity .25s` / `.4s`, `transform .25s cubic-bezier(.5,0,.5,1)`), only on AI pages at scale.
- **Screenshot treatment:** cropped, "vignette-blurred" edges (Gaussian fade to white), often one floating element tilted 3–6° with drop shadow (task card, popover) to imply interactivity; chat mocks have a gradient hairline border.
- **Iconography:** indigo single-weight line icons in 44px rounded tiles (`#EEF0FF` bg); product icons are solid colored rounded squares (Dashboards pink, Board blue, Gantt red, Chat purple, Docs blue, Whiteboards yellow, Forms purple, Calendar red "31", Time tracking teal).
- **Numbers:** stats in 56–72px Plus Jakarta 650 (light pages) or Sometype Mono (dark pages), labels mono caps above, description gray beneath.
